📢 系統服務與維護公告
本系統為家族專屬掃墓地圖協作平台，旨在提供永久免費、極速穩定且跨裝置運作的尋陵定位與紀錄服務。
🛠️ 雲端服務與核心技術
🌐 網頁託管 (Hosting) GitHub Pages (全球CDN)
🔥 雲端資料庫 (Database) Google Firebase (永不休眠)
📸 相片雲端主機 (Photos) imgbb (高清無限量)
🗺️ 地圖圖資 (Map Engine) Leaflet + OpenStreetMap
📜 系統版本與開發歷程
v1.4.0 2026-08-24 (最新版)
  • 全面遷移至 Google Firebase Firestore 雲端資料庫（告別 7 天休眠）
  • 串接 imgbb 高清圖片雲端，支援自動壓縮與無限張數上傳
  • 新增 2027/2028 年度掃墓打卡與地圖紅綠亮燈追蹤
  • 新增 1x~5x 全螢幕照片雙擊/滾輪放大與自由平移
  • 新增 一鍵「JSON 備份」與「依墓地自動建資料夾相片打包 (ZIP)」（含還原對照表）
  • 優化選單介面與「留言板 / 系統資訊」全螢幕自動隱藏地圖切換
v1.3.0 2026-06-04
  • 加入全螢幕相片滑動檢視器、箭頭 Slider 與 SortableJS 照片拖曳排序
  • 支援現場多照片預覽與切換
v1.2.0 2026-05-30
  • 導入密碼保護留言板功能，方便家族成員留言討論
  • 增加一鍵匯出 JSON 資料庫備份
v1.0.0 2026-05-29
  • 專案初始上線，支援 GPS 定位標記、一鍵 Google Maps 導航與墓地資料登記
